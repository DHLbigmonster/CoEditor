隐私

一句话：CoEditor 不联网、不上传、不收集遥测。下面逐条说清边界。

数据去向说明
你打开的文档只在你的机器上本地服务只监听 127.0.0.1，不接受外部连接
批注与保留要求你的文档目录写进 .marginalia/annotations.json，明文，你自己可以随时看和改
与 Agent 的传输本机进程之间Agent 通过本地 MCP / HTTP 读取；CoEditor 本身不向任何远端发送数据
诊断与遥测不存在没有埋点、没有崩溃上报、没有账号体系
官网本身静态页面本站不设账号、不写 Cookie、不引第三方统计脚本

需要你判断的地方：你把哪些要求交给哪个 Agent，是由你的 Agent 决定的。 CoEditor 只负责把这些要求放在本机一个它读得到的地方。如果那个 Agent 会把内容发到云端，那是它的行为， 不在 CoEditor 的控制范围内。
