获取 CoEditor

v1.6.0 首个公开测试版已发布（源码） —— 见 Releases。 暂时没有预编译安装包，下面是现在就能用的方式。

推荐：从仓库运行（一条命令）

git clone https://github.com/DHLbigmonster/CoEditor.git
cd CoEditor
node server.mjs ~/Documents

要求 Node.js ≥ 18。不需要 npm install —— 运行时依赖已经随仓库带走。

将来会有：macOS 应用包

计划提供签名的 macOS 应用（内含本地服务，双击即用）。在没有发布并验证之前，这里不会出现下载按钮 —— 空链接比没有链接更糟。

不包含什么

  • 不包含 AI 模型，也不含任何云端服务。
  • 不捆绑 LibreOffice。需要 PPT 完整排版预览时，界面会说明这是可选的本地组件，由你自己决定装不装。

怎么确认你下到的是真的：仓库地址是 github.com/DHLbigmonster/CoEditor。 发布安装包之后，我们会在 Releases 页面提供版本号与校验值。
