帮助

第一次使用

  1. 启动时把要看的文件夹传给它：node server.mjs ~/Documents；也可以在界面里点「打开文件夹…」。
  2. 左侧选文件；中间阅读；需要改文本文件时切到「编辑」。
  3. 选中一句话 → 批注 / 保留 / 删除线，写完不用点保存。

连接 Agent

左下角的状态灯有三种含义：

  • 连接 Agent：还没有 Agent 接过。点开可复制 MCP 配置。
  • 等待 Agent 读取：配置已复制，但还没有 Agent 真的读过。
  • 已连接：确实有 Agent 读过这批批注（判据是一次真实的读取，不是"配置写没写"）。

接入片段形如：

{
  "mcpServers": {
    "coeditor": { "command": "node", "args": ["<CoEditor 目录>/mcp-stdio.mjs"] }
  }
}

PPT 的完整排版预览

需要本机的 LibreOffice。装机后 CoEditor 会自动检测并使用；没装就走文字模式（能读文字、改文字、批注）。 我们不随包提供、也不自动安装这个组件。

数据与恢复

  • 批注：文档目录下的 .marginalia/annotations.json。
  • 编辑前的上一版：.marginalia/document-backups/。
  • 删掉应用不会删掉这两处；恢复就是把文件拷回去。
